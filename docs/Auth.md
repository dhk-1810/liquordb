## 회원 탈퇴, 계정 복구 처리
### 1. 회원 탈퇴
- 탈퇴 시점부터 1주일까지는 Soft Delete 상태를 유지함.
  - 이 기간동안 재로그인 시 계정 복구 가능.
- 기간 만료되면 매일 오전 3시에 작동하는 스케줄러가 Hard Delete 처리, 영구 삭제함.

### 2. 계정 복구
- WITHDRAWN 상태인 사용자가 로그인 시 유효기간이 짧은(5분) 엑세스 토큰만을 임시 발급함. (정식 로그인과 구분)
- 사용자가 동의 버튼을 클릭하면
  - 리프레시 토큰과 엑세스 토큰을 모두 발급해 로그인 처리함.
  - UserStatus를 ACTIVE로 변경함.
